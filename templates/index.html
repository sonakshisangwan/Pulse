Pulse – Student Quiz & Academic Performance System

A lightweight, practical web portal designed for engineering students to test subject knowledge, track quiz scores, and analyze academic performance over time.

{% if session.get('role') == 'student' %} Start Quiz Now View Performance Analytics {% elif session.get('role') == 'admin' %} Go to Admin Dashboard System Analytics {% else %} Student Login Student Register Admin Login {% endif %}

1. Student Quiz Engine

Randomly pulls 10 questions from our question bank. Complete the quiz on a single page with intuitive radio buttons and receive instant feedback.

2. Instant Grading & Feedback

Calculates total correct and incorrect responses, total marks, percentage, and assigns an academic grade (A, B, C, D, F) immediately upon submission.

3. Pandas & NumPy Analytics

Examines class performance using Python data science libraries. Computes highest, lowest, and average class scores alongside Matplotlib visualization charts.

4. Teacher & Admin Control

Allows faculty administrators to add, view, and remove questions from the central question bank with automatic Question ID allocation.

5. Secure Password Storage

User passwords are encrypted with standard SHA-256 cryptographic hashing before being stored inside CSV files.

6. Lightweight CSV Architecture

Zero complex database configurations. Built with pure Python, Flask, CSV file handling, and clean responsive CSS.
